# About Me

I've had the opportunity to work on several interesting projects during my
career. Here's some more details:

## Clinical Trial Management SaaS Platform

### Front-End Development Team Lead

- Developed application using React, NextJS, and styled MUI components in a monorepo
- Assisted lead architect and other team leads in deciding on technical strategies
- Developed component library based on styled MUI components
- Developed internal standards and tools to assist other team members
- Researched, customized, and integrated a third-party survey library
- Decided on API contracts with front-end and back-end team members

## Identity Protection Application

- Created application using React, React Router, Redux, and SCSS, integrated into larger site via a microfrontend pattern
- Assisted two other front-end developers, set techincal direction, and reviewed PRs

- Integrated third-party 3D globe visualization into React application

- Performed integration to add Gemini summary of vulnerabilities
